## Three real learner decisions

These questions inform implementation defaults; they do not block the completed
review or the progress/content fixes.

| Decision                                                              | Recommendation                                                                                                                                        | What would change it?                                                                                                                                            |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **What should improve first: reading, listening, or active use?**     | Assume reading, because these words came from reading. Use targeted contextual meaning recall first; separate reading pronunciation when needed.      | Listening-first moves audio contracts up. Speaking/writing-first increases selected collocation/form practice. It still does not require a card for every kanji. |
| **How much extra review time is rich passage practice worth to you?** | Use concise targeted reviews plus relevant context on demand, with a chosen daily time budget. Keep an MCD-first preset available.                    | If passage practice is more engaging and sustainable, make it primary and measure benefit per minute. Do not infer enjoyment or speed from a named method.       |
| **Should a different natural Japanese answer count as success?**      | For language use, accept reviewed alternatives; for spelling/source reconstruction, state the narrow target explicitly. Provide “also fits / repair.” | Exact source-word recall can be a deliberate goal, but a valid synonym then signals task mismatch rather than necessarily poor Japanese.                         |

Visible post-attempt English gloss, Japanese-first feedback, theme variety and
suggested context counts can be adjustable preferences. No new confirmation is
needed merely to recommend sensible defaults. Reopening MCD choices does not
authorize resetting existing progress or silently changing what a mature card tests.

## Definition of ready

Release readiness means every STANDARD rule has passed evidence or an explicit
release hold. A hold is not a waiver disguised as a green count. The current
verification is a baseline with known failures; rerun the affected checks against
each proposed fix. Native-device and qualified editorial checks must identify the
actual reviewer/environment and build. No model-generated “native approval.”
