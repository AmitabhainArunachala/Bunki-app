# Bunki SRS review

Date: 2026-10-04. Audited commit:
`d01dda7c2d3b312cae5ff1bec709ecae56e48ec4`, PR #116,
`claude/japanese-vocabulary-dbm2xr`. All source line references below refer to that
commit, not later changes. The review follows `docs/srs/CODEX_REVIEW_PROMPT.md` and
the learner's subsequent instruction that stated MCD choices are open to debate.

## Executive verdict

**Do not treat the current artifacts as release-ready. Keep FSRS-6; repair the
content, task measurement and progress handling before increasing deck size.**
For this reading-mined vocabulary, make targeted meaning retrieval the provisional
default and MCD a selective complement. This is a task-fit/workload judgment, not
proof that TSC beats MCD. Preserve both existing entry points while moving toward
one sense collection, distinct retrieval contracts and a coordinated queue.

The top five risks are:

1. **Lost progress:** `{}` restore empties a real ledger; quota failure advances
   the screen without saving. Review history is truncated and undo rewrites it.
2. **Unestablished public-release rights:** Aozora work-specific copyright is
   mislabelled public domain; ND/NC-ND and “personal study” records are distributed
   without demonstrated permission for the transformed outputs.
3. **Wrong learning material:** twelve MCD passages expose the answer twice;
   incorrect ruby, sense mismatches, false lexical matches and a clear Earth-axis
   factual error teach or reward the wrong answer.
4. **Invalid measurement and queue rules:** meaning recall, cloze and choices
   share state; choices auto-grade; sibling protection disappears on reopen;
   a ten-minute learning step can repeat immediately; the clock can crash grading.
5. **Incomplete delivery reliability:** cancelled gestures can grade, light
   themes fail contrast, long answers push controls below the phone viewport, and
   a fresh offline installation lacks scheduler dependencies. Native mobile remains unverified.

The five highest-value changes are: atomic persistence plus validated recovery;
sense/identity/rights-aware content validation; one append-only evidence adapter
with truthful timing; selective task enrollment within a shared collection; and
tested mobile/offline/Anki delivery generated from one registry.

Scope: **73 words, all 12 topics, 321 source records**; full-corpus scans;
**96 phone-width mode/theme/face screenshots**; actual Anki backend import and
changed-content reimport. Build, format, lint, **1,710 unit tests**, all **20 deck
checks** and **41 storage checks** passed. The broad corridor walk passed **225/226**;
the failing constellation-drag assertion is recorded, not hidden. Green existing
tests do not cover the demonstrated release blockers. No production fixes or
learner-data changes were made in this review.

## Corpus and sampling notes

MCD has **943 unique passage records**: 454 non-original and 489 labelled original
(51.9% original), generating 943 word and 654 character cards. The sentence deck
has 503 cards. These totals do not certify source authenticity, language quality or
rights. MCD records include 191 livedoor ND labels, 102 blanket Aozora PD, 82
Wikipedia, 43 Wikinews and 29 web “personal study”; sentence records include 194
web “personal study,” 39 livedoor ND and one WRIME NC-ND. Exact license/version and
permission must be resolved record by record.

Twelve MCD word-card fronts expose a repeated literal target:

`km-065-m04`, `km-109-m04`, `km-218-m05`, `km-083-m05`, `km-193-m04`,
`km-157-m04`, `km-076-m05`, `km-215-m04`, `km-252-m04`, `km-301-m06`,
`km-136-m04`, `km-021-m04`.

The sentence scan also finds repeated forms; these are not necessarily a problem
in meaning-reading mode but leak when switched to first-only cloze. Identical
sentences shared by different target words are not automatically duplicate defects:
