(about 584 MB). They were removed from this branch before it went to
`main`, so the repository and every future clone stay small.

Nothing was deleted. The full evidence set, including every image the
reports in this folder link to, is preserved at:

- branch `claude/r5-strict-20261010`, commit `ab0cc9c4cf27fd0daf9e1b98aaad40aeac81472a`

for example:

`https://github.com/AmitabhainArunachala/Bunki-app/tree/ab0cc9c4cf27fd0daf9e1b98aaad40aeac81472a/docs/redesign`
