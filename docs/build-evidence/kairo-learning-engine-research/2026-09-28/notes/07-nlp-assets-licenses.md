# Track 07 — Japanese NLP, data assets, and commercial licensing

Research cutoff and access date: **2026-09-28**. `Undated` means the source did not supply a reliable publication/revision date; access date is not a publication date. Product choices below are **DESIGN RECOMMENDATIONS**, not externally demonstrated outcomes. Bunki's existing asset counts are owner-supplied and **UNVERIFIED against repository files**. A displayed repository license is not proof that every upstream contribution has been cleared.

## Takeaway

Keep the product's dictionary and stroke assets, but make provenance and licensing executable build inputs. Prefer a pinned local tokenizer, EDRDG dictionaries, KanjiVG, audited Kanjium accent rows, licensed Tatoeba text, and commissioned content. Ship each adapted share-alike dataset as an identifiable asset package with attribution and the applicable license. Do not treat a code library's license as the license of its dictionary, model weights, training corpus, or audio. This separation is a design recommendation based on the distinct terms below.

The principal exclusions are **JParaCrawl**, **BCCWJ frequency lists**, **I-JAS redistribution**, **OJAD audio embedding**, and unlicensed NHK copying. They are useful research references, but the verified terms do not provide the commercial redistribution permission this app needs. `UNVERIFIED` assets must fail the production ingestion gate, not quietly become teaching material.

## Inferences

These are engineering recommendations, not measured claims:

1. Start with **deterministic lexical retrieval**. Embeddings are optional candidate retrieval; they never set known state, choose a sense without evidence, verify a Japanese sentence, or schedule a review.
2. Maintain an asset manifest containing `asset_id`, upstream URL, source date, retrieved date, pinned revision, SHA-256, exact license text, attribution text, allowed uses, prohibited uses, adaptations, and reviewer. Derived records carry parent asset IDs. Check production builds against a deny list for NC, research-only, absent-license and unresolved mixed-license assets.
3. Build-time bulk morphology may use a richer tokenizer; runtime must use the same pinned segmentation contract, or record explicit mapping migrations. Asset versions and migration choices must be reproducible from the learner record for “same ledger, same model.”
4. Reading verification must use lexical **sense + reading + surface form** rather than kanji-string membership. Dictionary-attested vocabulary does not establish grammaticality. A generated sentence with ambiguous reading/sense, unsupported grammar or unchecked register remains **UNVERIFIED** and cannot become an authoritative teaching card.
5. For the first release, use KanjiVG and commissioned audio; avoid introducing AnimCJK's mixed license, OJAD service coupling, or research-only corpus dependencies. Learner imports remain private data and do not confer redistribution rights.

## Gaps

- **UNVERIFIED:** the provenance and commercial rights of Bunki's existing core word subset, sentence bank, articles, mock papers and lessons. The build must audit these before claiming the package is commercially clear.
- **UNVERIFIED:** target-device memory, startup download size, worker latency and token/sense alignment error for every tokenizer candidate; no benchmark was run.
- **UNVERIFIED:** a commercial redistribution grant for OJAD dictionary extraction, NHK Easy, I-JAS or JParaCrawl; absence of a grant is a shipping blocker for those assets.
- **UNVERIFIED:** exact Creative Commons version of the Tanos/Waller grant. Retain the original permission page and seek clarification before standardizing the identifier.
- **UNVERIFIED:** comparative handwriting accuracy on learner-written kanji; licensed training data and browser recognition options require another focused evaluation.
- **UNVERIFIED:** available grammar inventory meeting all commercial rights, Japanese linguist review and cross-level coverage requirements. Original authoring is an effort item, not a free dataset assumption.
