FINDINGS (Japanese typography on dark screens — lane deliverable)

**1. System-font reality (drives everything)**
- Android: ZERO Japanese serif system fonts (only Noto Sans CJK). iOS: Hiragino Mincho ProN in exactly two weights (W3≈300–400, W6≈600–700). Yu Mincho: macOS/Windows only, NOT iOS. → A webfont is mandatory for cross-platform mincho; system fonts are fallback tier only.
- Stack: `--font-mincho: "Shippori Mincho B1", "Shippori Mincho", "Hiragino Mincho ProN", "Hiragino Mincho Pro", "Yu Mincho", YuMincho, "BIZ UDMincho", "Noto Serif JP", "Noto Serif CJK JP", serif;` (webfont first so iOS/Android match; `font-weight:800` degrades to Hiragino W6 on iOS — acceptable).

**2. lang="ja" correctness trio**
Without `lang="ja"` on Japanese nodes, mobile Chrome/Safari can resolve fallbacks through Chinese fonts (PingFang SC / Noto Sans SC) → CN glyph variants of 直/骨/海 — a correctness bug for a JP-learning app. Put `lang="ja"` on word/reading/sentence nodes; style via `.card :lang(ja){font-family:var(--font-mincho)}`. Add `font-synthesis:none` (kills faux-bold that destroys brush forms) and `-webkit-font-smoothing:antialiased` on dark (light-on-dark otherwise blooms).

**3. Face-per-role (Google Fonts)**
- Big word: **Shippori Mincho B1** (display cut of the oldstyle metal-type revival; large brushy kana; strongest "1600s Japan" feel; weights 400/500/600/700/800 — use 700/800).
- Reading: **Yuji Syuku** (real shodō calligraphy by Yuji Kataoka; single weight 400; kana coverage complete — kana-only use is safe). Alternative if too ornate: **Klee One 600** (textbook semi-cursive, "human hand").
- Grade seals: **Kaisei Tokumin 800** (heavy stamp/hanko-like mincho).
- Runner-up display: Zen Old Mincho 700/900. Avoid: Hina Mincho and any weight-400 mincho on dark (hairlines vanish).
- Web deploy link: `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin><link href="https://fonts.googleapis.com/css2?family=Shippori+Mincho+B1:wght@700;800&family=Yuji+Syuku&display=swap" rel="stylesheet">`

**4. Seal micro-subset trick**
再難良易 is a fixed 4-glyph set → Google Fonts `&text=` serves a ~5–10KB (est.) micro-font:
`https://fonts.googleapis.com/css2?family=Kaisei+Tokumin:wght@800&text=%E5%86%8D%E9%9B%A3%E8%89%AF%E6%98%93&display=swap`
`.seal{font-family:"Kaisei Tokumin","Hiragino Mincho ProN",serif;font-weight:800;font-size:22px;line-height:1}` inside ≥48×48px tap targets (spec floor 44).

**5. Subset economics (offline PWA)**
Google Fonts slices JP fonts into ~120 unicode-range woff2 chunks (kana chunk ~15–40KB; a session pulls ~60–250KB/weight — fine for web deploy, NOT offline-safe). PWA build: deck-driven self-hosted subsets — extract every unique char from the SRS deck JSON; ~2k-word deck ≈ ~1,500 kanji ≈ 450–750KB woff2 per weight (est.); kana-only Yuji Syuku ≈ 25–50KB (est.).
```
pip install fonttools brotli
pyftsubset ShipporiMinchoB1-ExtraBold.ttf --text-file=deck-chars.txt \
  --unicodes="U+3000-303F,U+3041-309F,U+30A0-30FF,U+FF01-FF60,U+FF61-FF9F" \
  --layout-features='palt,vert,vpal,kern' --flavor=woff2 \
  --output-file=shippori-b1-800.subset.woff2
```
(same for YujiSyuku-Regular.ttf with kana/punct unicodes only). `font-display:swap`; precache both in the service worker.

**6. Type scale @390px (330–346px usable). CJK fills the full em → single-line display lh 1.1–1.2; multi-line JA body lh 1.8–2.0 (much looser than Latin).**
- Front word: char-count-adaptive (below), lh 1.12, sumi `#211d16` on washi `#ece5d3` (~13:1).
- Reading: 28px / 1.4, Yuji Syuku.
- EN senses: 17px italic / 1.55, ls 0.01em, `font-family:"Iowan Old Style",Palatino,Georgia,"Times New Roman",serif`, color `#5b5344` on washi (AA).
- JA example sentence: 17.5px / 1.9, ls 0.04em, weight 500–600.
- EN gloss: 14px / 1.5 italic `#6e6656`.
- SRS meta: 11px / 1.3, ls 0.12em uppercase.
- Seal glyphs: 22px in 48px+ targets.

**7. Letter-spacing norms + centering fix**
JA body: 0–0.05em. Standalone kana reading line: 0.12–0.18em reads ceremonial. 2–3 kanji display words take generous aki like a hanging scroll. CSS letter-spacing adds a trailing gap → re-center with `padding-left` equal to the ls value.
JS sets `data-len`: len 1–2 `{font-size:76px;letter-spacing:.35em;padding-left:.35em}` · len 3 `{64px;.2em}` · len 4 `{52px;.1em}` · len 5–6 `{40px;.05em}` · len 7+ `{32px;.02em;font-feature-settings:"palt" 1}`. Mincho reading: `letter-spacing:.15em;padding-left:.15em`. Yuji Syuku: cap at .05em (built-in brush rhythm).

**8. Hairline death on dark**
Weight-400 mincho horizontals fall below 1 device px on the dark stage. Fix: weight 700–800, or `text-shadow:0 0 .5px currentColor` (fattens without blur), or `-webkit-text-stroke:.25px currentColor`. Never 400-weight mincho <24px on dark. On the light washi card, 500–600 is fine.

**9. Reading red, WCAG-computed**
- On washi `#ece5d3`: deep vermilion (shu-iro) `#b7282e` = **4.98:1** (AA normal text).
- On dark stage `#0f1013`: `#e8604c` = **5.6:1**, or `#ff6b5e` = **6.9:1**. Crimson `#dc143c` on near-black = only 3.9:1 (fails AA <24px).
- Tokens: `--ink:#211d16; --washi:#ece5d3; --reading-red-on-washi:#b7282e; --reading-red-on-dark:#e8604c;`

**10. Calligraphy-not-UI rendering for the reading**
(a) real brush face (Yuji Syuku); (b) optional vertical side column, as readings annotate hanging scrolls: `.reading-v{writing-mode:vertical-rl;font-size:22px;letter-spacing:.18em;max-height:12em;position:absolute;right:18px;top:24px}`; (c) brush-wipe reveal instead of fade: `.reading{mask-image:linear-gradient(90deg,#000 var(--wipe),transparent calc(var(--wipe) + 12%))}` animate `--wipe` 0%→112% over 600ms `cubic-bezier(.22,1,.36,1)` (registered @property or keyframed mask-position; vertical variant wipes 180deg); (d) ink bleed: `text-shadow:0 0 .5px currentColor,0 1px 6px rgba(183,40,46,.18)`. Reduced motion: `@media (prefers-reduced-motion:reduce){.reading{mask-image:none;animation:none;transition:opacity 200ms linear}}`.

**11. Sentence typesetting (de-crowds the back for free)**
`.sentence-ja{line-break:strict;word-break:normal;overflow-wrap:anywhere;hanging-punctuation:allow-end;text-align:left;text-spacing-trim:space-all /* Safari 18+/Chrome 128+, progressive */}`. Keep full-width metrics in body (no palt); reserve `"palt"` for the display word at 4+ chars.

**12. Fallback-flash control**
Shippori and Hiragino are both full-width CJK → metric-matched local fallback makes swap invisible for JP: `@font-face{font-family:"Shippori Fallback";src:local("Hiragino Mincho ProN");size-adjust:100%;ascent-override:88%;descent-override:12%;line-gap-override:0%}` then `--font-mincho:"Shippori Mincho B1","Shippori Fallback",serif`. Android has no local mincho — accept a Noto Sans flash on first visit; SW-cached subset is instant after.

TOP 5 RECOMMENDATIONS
1. Self-host two deck-driven subsets: Shippori Mincho B1 @800 (deck kanji+kana, ~450–750KB est.) for word/JA text; Yuji Syuku kana-only (~25–50KB est.) for the reading. Android has no system mincho — the webfont is load-bearing.
2. Char-count-adaptive word sizing with scroll-style aki: 1–2 chars 76px/ls .35em → 3: 64px/.2em → 4: 52px/.1em → 5–6: 40px/.05em → 7+: 32px+palt; lh 1.12; padding-left = letter-spacing to keep centering true.
3. Reading = calligraphy: Yuji Syuku 400 @28px/1.4 (or 22px vertical-rl column), `#b7282e` on washi (4.98:1) / `#e8604c` on dark (5.6:1), 600ms cubic-bezier(.22,1,.36,1) mask wipe, opacity-only under prefers-reduced-motion.
4. Seals 再難良易: Kaisei Tokumin 800 via `&text=` micro-subset (~5–10KB), 22px glyphs in ≥48px targets.
5. Correctness trio on every JP node: `lang="ja"` + `font-synthesis:none` + never 400-weight mincho on dark (≥600 or `text-shadow:0 0 .5px currentColor`); sentences get `line-break:strict` + `hanging-punctuation:allow-end` + lh 1.9.
