# Bunki / KAIRO 1.2.2-rc.1

Local development candidate prepared 2026-11-08 (Asia/Tokyo) for a draft stacked PR.
This is not publication, a merge, or a deployment.

## Changes

- Refresh the complete canonical shared-study distribution from reviewed Nihongo
  source `423b9e5d970be74db94f8c7f2be89a8e73c46fd6`. Optional answer-side kanji
  exploration and the read-only canonical Record report preserve the simple
  prompt → Reveal → four grades loop. Enrichment covers two selected sound
  families and seven contrasts, not comprehensive kanji coverage; related
  vocabulary comes from the loaded catalog.
- The canonical report distinguishes exposure, vocabulary self-ratings, delayed
  first outcomes, missing checks and coverage. These do not prove kanji or
  handwriting mastery; later success does not replace a first outcome. The
  proposed 20 → 30 → 40 experiment never increases workload automatically.
- At outer viewport widths up to 360px, only a main element directly hosting
  shared study uses 8px horizontal gutters. At 320px this gives the iframe 304px,
  respecting the canonical 300px minimum. Ordinary main gutters remain 18px;
  canonical CSS is copied unchanged, with no scaling or overflow workaround.
- Preserve the latest finish features, complete answers, offline ledger, new G3
  modules and existing review behavior. Remove only 184 unused named imports
  from the Corridor entry module, retaining module evaluation and order. The
  inherited finish VM fixture gains the missing speech-retirement presentation
  stub; actual review runtime and assertions remain unchanged.
- Normalize formatting in seven owned ordinary scripts and shared-study tests,
  retaining every assertion. Frozen corpus, generated modules and unrelated
  formatting debt are unchanged.

## Data and compatibility

Learner-data epoch remains 1, migration is `none`, and `rollbackCompatible` is
`true`. Learner ownership, card IDs, saved records, backup interpretation, pinned
FSRS behavior and the complete existing ledger are preserved. All nine canonical
behavior modules, reducer, replay dependencies, verifier and content binding are
unchanged. No content is regenerated and no learner history is migrated.

The supported local integration remains the explicit shared-study preview route
for N2, N1, senmon, kotoba-master and shared grammar. A real bound host still
requires its own identity, storage, pairing, transport and permit authority;
this candidate supplies no production pairing or live sync. The isolated preview
has its own installation and limited synthetic initial grant. Legacy decks,
saved-word/kanji/sentence/question reviews, world/course hooks and the outer Bunki
Record remain disconnected from the canonical distribution and retain their
existing identities and histories. Existing Bunki record sync is not a canonical
v4 study transport. Any real cutover still requires a migration and old-client
fencing plan.
