# Bunki / KAIRO 1.3.0-rc.1

Development candidate prepared 2026-11-09 (Asia/Tokyo), tracked in draft PR #145. This candidate follows 1.2.2-rc.1; no production merge, publication or deployment is authorized by this version.

## Changes

- Connect the supported N2, N1, Senmon, Kotoba Master and shared-grammar routes to the same canonical Nihongo study UI, review journal and optional durable audio-pack host through an [explicitly bound host](../docs/srs/SHARED_STUDY_ENGINE.md#bound-development-host-and-ordinary-routes). Production startup remains unchanged.
- Preserve complete answers, Japanese/English/bilingual labels, optional kanji exploration, dictionary actions and the read-only canonical Record report. The outer Bunki Record and unmapped legacy surfaces remain separate.
- Regenerate the complete canonical distribution from the [independently pinned runtime source](../scripts/shared-study-pin.json), with closure admission. Repair host startup retry, stale review ownership, offline restart, private audio-store observation and verifier authentication.

## Data and compatibility

Learner-data epoch remains 1. Card and task identities, learner ownership, persisted reviews, reducer and replay dependencies are preserved. No real learning history is migrated. An independently reviewed replica-backend correction aligns queue/custom/permit selection with the existing effective learner-day rule. The frozen content producer remains [separately pinned](../scripts/ci/canonical-decks-source.json).

Vocabulary ratings do not prove kanji mastery or handwriting ability, and this candidate does not increase daily workload automatically. Audio infrastructure is shared; complete ElevenLabs/Kore recordings and listening acceptance are outstanding.
