# Bunki / KAIRO 1.2.1

Planned release date: 2026-11-08 (Asia/Tokyo). Publication is established by the GitHub Release and live build identity.

## Changes

- **No learner-visible change.** The app is the 1.2.0 app; this release exists
  because every production pull request carries a new, increasing version.
- **The test suite runs again on GitHub.** GitHub moved its `ubuntu-latest`
  runner from Ubuntu 24.04 to Ubuntu 26.04 after 1.2.0 shipped. Ubuntu 26.04
  carries ICU 76, and the WebKit build that Playwright 1.63 installs needs
  `libicudata.so.74`, so every WebKit check and vitest's two WebKit browser
  test files failed before the app loaded (control run 42405307658 on main).
  The CI workflow now pins `ubuntu-24.04`, the image the suite was last green
  on (2026-10-14). A later release can move Playwright forward and return to a
  current image.

## Data and compatibility

No learner-data change. Card identities, FSRS parameters, backups and the
learner-data epoch are unchanged (epoch 1, migration none, rollback compatible).

## Verification

The pull request's own CI run on the pinned image is the check: plan, build,
native, the fast shards and the battery. The configuration touched is
`runs-on` in `.github/workflows/ci.yml`, plus the one line in
`scripts/verify-release-gates.mjs` that pins the expected runner label for the
shard jobs; no product source, test, data or dependency changed. Known limitation: the pin is a hold, not a fix of the Playwright and
ICU mismatch, which a later Playwright upgrade resolves.
