# Bunki / KAIRO 1.3.0-rc.4

Candidate prepared on 2026-11-25 (Asia/Tokyo).

## Changes

The learning application uses a patched validator and URI decoder. Expo deep links retain their query and fragment handling. The static reading, assessment, feed and record modules now each package one copy of the application validator. The combined download size falls, while the standalone learning module grows.

## Data and compatibility

Learner-data epoch 1. The UTF-16 limits on saved Japanese text, identifiers and remote operations match rc.3, including for supplementary kanji such as 𠮷. Assessment JSON Schemas retain their published limits. Card identities, review history, FSRS scheduling, backup compatibility and the shared Nihongo Study engine pin carry forward from rc.3. Existing records remain readable on rollback.

## Verification

Acceptance covers the affected workspaces, offline review replay, generated core initialization and exported schemas, the desktop bridge, and Expo deep links in Chromium. Physical-device acceptance and the remaining Expo toolchain audit findings are open release work. [Dependency review](https://github.com/AmitabhainArunachala/Bunki-app/pull/156)
