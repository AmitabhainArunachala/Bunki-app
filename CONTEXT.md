# Kairo learning

Kairo keeps the learner's encounters, unfinished work and explicit practice responses connected to their sources.

## Language

**Sentence draft**:
Unfinished text for one selected sentence-practice mode. It can be empty and is neither a submitted response nor an assessment.
_Avoid_: Attempt, answer, assessed production

**Submitted revision**:
The exact draft editing identity chosen by an explicit Save response action. A later edit is a distinct revision even when its text equals the submitted text.
_Avoid_: Latest text, matching answer

**Source reading cue**:
The supplied reading of one exact word occurrence, with its source annotation and review status retained. Matching it checks that word's reading in this practice; it does not certify the annotation or every reading of its kanji.
_Avoid_: Verified pronunciation, standalone kanji mastery

**Source reference**:
A kept link with its exact encountered address and capture time. It identifies something the learner chose to return to; it contains no source text and grants no permission to process that text.
_Avoid_: Synced article, source permission, verified source

Received practice history keeps the existing paper-and-ink reading room. A response received from another device is read-only and explicitly separate from scores, official results and local full attempts. Show exact questions/options only when their saved form and item versions match locally available content; otherwise preserve the response text or reference and explain the unavailable version. Keep local ongoing practice, answers and clock intact when history refreshes. Back returns to the same history row. Different records remain visible alternatives, and revocation/deletion removes only the received view. Record-sync wording names this bounded behavior without claiming complete retained attempts, all-record synchronization or live-device acceptance.
